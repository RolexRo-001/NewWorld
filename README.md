# NewWorld

Repositorio de extensiones para Aniyomi.

## Información

NewWorld es un repositorio comunitario para distribuir extensiones compatibles con Aniyomi.

## Repositorio

Este repositorio utiliza la estructura compatible con los repositorios de extensiones de Aniyomi.

## Fuente

Las extensiones sincronizadas desde repositorios externos conservan sus respectivos nombres, versiones y metadatos.

## Uso

El repositorio podrá añadirse a Aniyomi utilizando el índice publicado en la rama `repo`.
